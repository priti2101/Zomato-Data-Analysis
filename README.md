# Zomato Data Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of Zomato restaurant data using Python. The objective is to analyze restaurant ratings, customer votes, online ordering preferences, and restaurant types to identify useful insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis Performed
- Data loading and preprocessing
- Handling restaurant rating values
- Analysis of restaurant ratings
- Identifying restaurants with maximum votes
- Analyzing online and offline order preferences
- Analyzing restaurant types and customer votes
- Creating pivot tables and heatmaps
- Data visualization

## Key Insights
The analysis explores:
- Distribution of restaurant ratings.
- Restaurant types receiving the highest votes.
- Customer preferences for online ordering.
- Relationship between online ordering and restaurant ratings.

## Project Files
- `Zomato_Data_Analysis.ipynb` – Jupyter Notebook containing the complete analysis.
- `Zomato-data-.csv` – Dataset used for analysis.
- `requirements.txt` – Required Python libraries.

## How to Run
1. Clone this repository.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Open the Jupyter Notebook.
4. Run the cells to explore the analysis.
